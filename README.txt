2. Open Command Prompt in this folder.
3. Run: pip install -r requirements.txt
4. Set your BotFather token as the MAILPAY_BOT_TOKEN environment variable.

set MAILPAY_BOT_TOKEN=YOUR_BOTFATHER_TOKEN
python bot.py
